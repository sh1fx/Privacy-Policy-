# 🔒 Privacy Policy | นโยบายความเป็นส่วนตัว

This document explains what data is collected and stored by the bot when used inside Discord servers.  
เอกสารฉบับนี้อธิบายเกี่ยวกับข้อมูลที่บอทมีการจัดเก็บเมื่อถูกใช้งานภายในเซิร์ฟเวอร์ Discord

---

## 📦 Data Collection | ข้อมูลที่มีการจัดเก็บ

### 1. Server ID
**EN**
- Automatically stored when the bot joins a Discord server.
- Used to identify and manage server-specific configurations.

**TH**
- ถูกบันทึกอัตโนมัติเมื่อบอทถูกเพิ่มเข้าสู่เซิร์ฟเวอร์
- ใช้สำหรับแยกและจัดการการตั้งค่าของแต่ละเซิร์ฟเวอร์

---

### 2. Webhook ID
**EN**
Channel IDs are stored only when a feature or system is enabled, such as:
- Counting Game System
- Chat System
- Other bot features

Data is saved **only after administrators enable the feature**.

**TH**
Channel ID จะถูกบันทึกเฉพาะเมื่อมีการเปิดใช้งานระบบ เช่น
- ระบบเกมนับเลข
- ระบบพูดคุย
- ระบบคำสั่งหรือฟีเจอร์อื่น ๆ

ข้อมูลจะถูกบันทึก **เฉพาะเมื่อผู้ดูแลเซิร์ฟเวอร์เปิดใช้งานระบบเท่านั้น**

---

### 3. Webhook URL
**EN**
Some bot features require frequent message delivery (e.g. message edit/delete logs).  
Due to Discord rate limits, Webhooks may be used to send messages efficiently.

**TH**
บางระบบของบอทจำเป็นต้องส่งข้อความจำนวนมาก เช่น
- แจ้งเตือนการแก้ไขข้อความ
- แจ้งเตือนการลบข้อความ

เนื่องจาก Discord มีข้อจำกัดในการส่งข้อความ (Rate Limit)  
บอทจึงใช้ Webhook เพื่อช่วยส่งข้อความแทนในบางกรณี
